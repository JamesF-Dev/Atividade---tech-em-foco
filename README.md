# Tech em Foco

Site estático desenvolvido com HTML e CSS. Possui:
- Página inicial com coleção de temas e imagens;
- Página de detalhes com informações completas;
- Página sobre o autor;
- Cabeçalho, menu de navegação e rodapé em todas as páginas.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `tech-em-foco`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)** e clique em **Save**.
6. Aguarde a publicação. O endereço ficará parecido com `https://SEU-USUARIO.github.io/tech-em-foco/`.
